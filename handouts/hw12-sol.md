# HW12 solutions: Invariants

## Exercise 1

(i)

- **Length is a strong invariant.** Each rule rewrites two letters by two letters, and the rest of the word is unchanged.
- **The number of `a`s is not.** `aa -> bb` takes that number from $2$ to $0$.
- **The parity of the number of `a`s is a strong invariant.** `ab <-> ba` preserves the number of `a`s. `aa -> bb` decreases it by $2$, so the parity is unchanged. Letters outside the rewritten substring contribute the same number on both sides.
- **The parity of the number of `b`s is a strong invariant.** Swaps preserve the number of `b`s. `aa -> bb` increases it by $2$.

(ii) `aa -> bb` takes a word with no `b` to a word with two `b`s, so $Q(\texttt{aa})$ is false and $Q(\texttt{bb})$ is true. The values differ, so $Q$ is not strong.

It is weak. `ab <-> ba` preserves the number of `b`s, and `aa -> bb` increases it by $2$. The number of `b`s never goes down, so if it was at least $1$ before a step, it is still at least $1$ after.

(iii) Use the parity of the number of `a`s. `ab` has one `a` and `bb` has none, so the parities differ.

A strong invariant is constant not only on single steps but on whole chains, including backward steps: if $w\to v$ then $P(w)=P(v)$, so $P$ is constant on $\stackrel{\ast}{\longleftrightarrow}$-classes. Different values imply the words are not equivalent, and in particular neither rewrites to the other in any number of steps.

**Remark.** The swaps rearrange letters arbitrarily, and `aa <-> bb` changes the number of `a`s by $\pm 2$. So two words are equivalent exactly when they have the same length and the same parity of the number of `a`s. For each $n\ge 0$ that gives two classes (one for each parity), except that the empty word is alone in length $0$.

## Exercise 2

(i) Check each rule.

- `ab <-> ba` does not change either count, so $P_a$, $P_b$, and $P_1$ all stay the same.
- `aa ->` (the empty word) deletes two `a`s and no `b`. The parity of the number of `a`s is unchanged, and both facts about `b`s are unchanged.
- `b -> bbb` adds two `b`s. The parity of the number of `b`s is unchanged. The step applies only to a word that already has a `b`, and it does not delete `b`s, so "at least one `b`" stays true. It also stays false on words with no `b`, because no rule creates a `b` from nothing.

(ii) Invariance alone does not cap the number of classes: it only says that words with different $P$-values lie in different classes. Completeness is the converse, so classes are in bijection with the values $P$ actually takes. There are $2^3 = 8$ possible triples, so a complete $P$ gives at most $8$ classes.

$P_b$ true and $P_1$ false would mean "the number of `b`s is odd" and "there are no `b`s". That cannot happen, for either parity of the number of `a`s. At most $6$ triples occur, so if $P$ is complete there are at most $6$ classes.

(iii) One word for each possible triple:

| word | #`a` even? | #`b` odd? | at least one `b`? |
|:-----|:----------:|:---------:|:-----------------:|
| $\varepsilon$ | yes | no | no |
| `a` | no | no | no |
| `bb` | yes | no | yes |
| `b` | yes | yes | yes |
| `abb` | no | no | yes |
| `ab` | no | yes | yes |

The six values of $P$ are different. By (i), equivalent words have the same value, so these six words lie in six different classes. That shows there are at least six classes. The matching upper bound is (ii), which still depends on completeness, proved in (iv). Together they give exactly six.

(iv) If $w\stackrel{\ast}{\longleftrightarrow} v$, then $P(w)=P(v)$, because each rule preserves $P$ and equivalence is generated by using rules forward and backward.

Conversely, assume $P(w)=P(v)$. The swaps `ab <-> ba` are the adjacent transpositions, so they generate every rearrangement: $w$ is equivalent to $\texttt{a}^{n}\texttt{b}^{m}$ where $n$ is the number of `a`s and $m$ the number of `b`s.

The rule `aa ->` may be used backward, which inserts `aa` anywhere, and forward, which deletes `aa`. So $\texttt{a}^{n}\texttt{b}^{m}$ is equivalent to $\texttt{a}^{n \bmod 2}\texttt{b}^{m}$.

The rule `b -> bbb` may be used backward on three consecutive `b`s, which deletes two `b`s. After the letters have been gathered, the `b`s form one block, and we may repeat until $0$, $1$, or $2$ `b`s remain:

- $m = 0$ stays $0$ (no rule creates a `b`);
- $m$ odd reduces to $1$;
- $m$ even and at least $2$ reduces to $2$ (from `bb` one cannot reach $\varepsilon$).

Therefore every word is equivalent to exactly one of $\varepsilon$, `a`, `b`, `ab`, `bb`, `abb`, and the representative is determined by the parity of $n$, the parity of $m$, and whether $m \ge 1$. Those are the three components of $P$. Same $P$ means the same representative, hence $w\stackrel{\ast}{\longleftrightarrow} v$.

So $P$ is complete, and the six words in the table are a full set of representatives.
