# Coding Assistant Rules

This folder contains rules and guidelines for AI coding assistants working on this project.

## Files

Rules and paper/bibliography workflows will be added as needed (see the 2025 course repo for precedents).

## Usage

When working on this project, coding assistants should:
1. Maintain consistency with existing patterns
2. Prefer UK spelling in course prose where applicable
3. Ask for clarification if rules conflict or are unclear
4. Prefer copying/adapting material from `CPSC-354-programming-languages-2025` rather than inventing new lecture content from scratch
