# Homework 10 (Lambda-calculus interpreters)

This homework connects the pen-and-paper lambda calculus from Homework 6
with the interpreter used in Programming Assignment 2.

Recall:

- application associates to the left, so `x y z` means `(x y) z`;
- the body of a lambda extends as far right as possible, so `\x. x y`
  means `\x. (x y)`;
- a substitution $M[N/x]$ replaces the free occurrences of $x$ in $M$
  by $N$;
- bound variables may be renamed to prevent variable capture.

We represent abstract syntax trees using these Python tuples:

```python
('var', name)
('lam', parameter, body)
('app', function, argument)
```

For example, `(\x. x) y` has the AST

```python
('app', ('lam', 'x', ('var', 'x')), ('var', 'y'))
```

## Exercise 1: From concrete syntax to ASTs

Write the AST of each term in Python tuple notation.

1. `x y z`
2. `x (y z)`
3. `\x. x y`
4. `(\x. x) y`
5. `\x.\y. x (y x)`

Which of the terms above would change meaning if one pair of parentheses
were removed?

## Exercise 2: Free variables and safe substitution

1. `\x. x y`
2. `\x.\y. x z`
3. `(\x. x y) (\y. y z)`

### (b) Substitution

Perform each substitution. Rename bound variables where necessary.

1. $(x\ z)[y/x]$
2. $(\lambda x.\,x\ z)[y/x]$
3. $(\lambda y.\,x\ y)[y/x]$

Explain why the naive answer `\y. y y` to the third substitution is
incorrect.

## Exercise 3: Evaluation with variable renaming

```text

```

remain free throughout the computation.

Then write the AST of the normal form.
